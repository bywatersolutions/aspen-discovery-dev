#### Cover Images
- Cover images that are already cached are sent without starting up the rest of Aspen, so a page of results no longer runs a dozen database queries for every cover. The cover Cache-Control header is also fixed so browsers and CDNs cache covers for two weeks. ([DIS-XXXX](https://aspen-discovery.atlassian.net/browse/DIS-XXXX)) (*KMH*)

#### Docker
- The Docker image publish workflow can now be run manually from GitHub Actions, either to publish the selected branch as latest or to rebuild and publish the images for any existing release tag. ([DIS-3085](https://aspen-discovery.atlassian.net/browse/DIS-3085)) (*JOM*)

#### Reports and Statistics
- Usage statistics are added up in shared memory and written every few seconds, instead of every request updating the same rows. ([DIS-XXXX](https://aspen-discovery.atlassian.net/browse/DIS-XXXX)) (*KMH*)

#### SSO

#### Searching
- Search history is no longer saved for crawlers, search results pages ask search engines not to index them, deep pages of results are limited to page 100 for visitors who are not logged in, and robots.txt keeps crawlers out of facet, sort and paging links. ([DIS-XXXX](https://aspen-discovery.atlassian.net/browse/DIS-XXXX)) (*KMH*)

#### Series

#### Server Setup
- Aspen keeps settings, translations and other data read on every request in APCu shared memory when the php-apcu extension is installed, and the installer and Docker image now install it. Sessions are no longer saved when nothing is stored in them or when they belong to crawlers. ([DIS-XXXX](https://aspen-discovery.atlassian.net/browse/DIS-XXXX)) (*KMH*)
- Added install/migrate_debian_to_php_fpm.sh to move a Debian server from mod_php to PHP-FPM, with a separate pool for visitors who have a session so crawlers cannot use up every PHP worker. ([DIS-XXXX](https://aspen-discovery.atlassian.net/browse/DIS-XXXX)) (*KMH*)
